Deborah C. Alikwe portfolio: static site (HTML, CSS, JS, images). No build step.

Deploy on Vercel (free):
1. Create a free GitHub account and a new repository, e.g. "portfolio".
2. Upload the CONTENTS of this folder (index.html must be at the top level).
   GitHub's web uploader takes up to 100 files per upload, so upload the
   "assets" folder first, then the "work" folder in two or three batches,
   then index.html, 404.html and this file. (GitHub Desktop uploads everything at once.)
3. On vercel.com, sign in with GitHub, click "Add New > Project", import the repository,
   leave Framework Preset as "Other", and click Deploy.
4. Your site goes live at something like portfolio-xxxx.vercel.app.
   Rename it under Project > Settings > Domains (e.g. deborahalikwe.vercel.app).
